# Worklog — Worklog Operating Convention (2026-09-22)

## 목적

RNA 기반 실험 프로젝트의 작업 이력을 추적할 수 있도록, 이후의 실제 작업 세션마다 독립적인 번호형 worklog를 `docs/`에 추가하기로 했다.

## 이번 세션에서 한 일

`AGENTS.md`의 worklog 규칙을 확인하고 적용 방침을 정했다. 기존 `docs/`에는 번호가 붙은 worklog가 없으므로, 이 문서를 첫 번호인 `01`로 생성했다.

## 적용 방침

각 후속 세션은 가장 큰 기존 문서 번호의 다음 번호를 사용하고, `NN_WORKLOG_<작업_설명>.md` 형식으로 새 문서를 만든다. 로그에는 작업 목적, 수행 내용, 근거가 있는 결과 및 평가 조건, 남은 과제를 간결한 서술로 기록한다. 이전 로그는 수정하거나 덮어쓰지 않는다.

## 결과와 한계

이번 세션은 실험이나 모델 평가를 수행하지 않았다. 따라서 성능, gate, case에 관한 실험적 판정은 없다.
