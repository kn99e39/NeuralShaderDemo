# Worklog — Worklog Directory Policy (2026-09-22)

## 목적

앞으로의 세션 worklog를 일반 문서와 분리해 `docs/worklogs/`에서 관리하도록 위치 규칙을 바꿨다.

## 수행 내용

기존 번호형 worklog가 `docs/worklogs/`에 보존된 상태를 기준으로, `AGENTS.md`의 worklog 기본 위치, 번호 탐색, 파일명 및 정정 사례 경로를 새 위치로 갱신했다. 오래 유지되는 일반 문서는 계속 `docs/`에 둘 수 있도록 구분을 유지했다.

## 결과와 한계

이번 세션은 문서 관리 규칙만 변경했다. 실험, 실행 환경, 성능 또는 gate에 관한 새 측정과 판정은 없다.
